# src ディレクトリ構成方針

`docs/requirements.md` のコア機能(3〜6章)を踏まえ、責務ごとに以下のディレクトリへ分割する。

- `engine/`
  コマンドインタプリタ・仮想ファイルシステム(VFS)・採点エンジンなど、UIに依存しないロジック層。
  シェル構文解析、組み込みコマンド実行、VFSスナップショットの読み込み・状態更新、模範解答との突き合わせ判定を担う。
  React Native / Expo に依存しない純粋な TypeScript として実装し、将来的な単体テスト・別プラットフォームへの流用を容易にする。

- `ui/`
  画面(screens)と再利用可能なコンポーネント(components)。
  `engine/` が提供する型・関数を利用して描画のみを担当し、判定ロジックを持たない。

- `content/`
  章・ユニット・演習の定義データ、VFSシードデータ、解説文などの静的コンテンツ。
  `Chapter` / `Exercise` / `VfsSnapshot` (要件定義書6章のデータモデル)に対応するデータをここに配置する。

- `navigation/`
  React Navigation の Navigator 定義・画面遷移の型定義。
  章一覧画面→演習画面など、画面間遷移の配線のみを担当する。

依存の向きは `content` → `engine` → `ui` / `navigation` を基本とし、逆方向の依存(`engine` が `ui` に依存する等)は避ける。
